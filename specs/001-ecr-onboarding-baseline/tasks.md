# Tasks: ECR → Snyk Onboarding (as-built baseline)

**Input**: Design documents from `specs/001-ecr-onboarding-baseline/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**As built**: the code at `f035a43` delivers every task marked `[X]` in Phases 1 to 7, and the
convergence fixes deliver Phase 8 (2026-11-24). This list records how that work
breaks down by story, so an engineer extending the tool can find each part. Open tasks (`[ ]`) come
from the [open items in research.md](research.md#open-items); none of them blocks feature 002.
Generated by `/speckit-tasks` on 2026-11-24, after the plan.

**Tests**: included. Constitution Principles I and V require unit tests of the delete scope and an
offline `make check`. The plan's [traceability table](plan.md#requirement-traceability) names the test
for each requirement. The code came first, so the template's test-first order does not apply to the
`[X]` tasks. The open test tasks (T031, T042) cover behavior that already exists: they should pass
when written, and a failure is a defect.

**Organization**: grouped by the spec's user stories, each verified on its own
([quickstart.md](quickstart.md), section 2).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies)
- **[Story]**: US1 to US4, the spec's user stories

## Path Conventions

A CLI tool plus a Terraform module, per [plan.md](plan.md#project-structure): `scripts/`,
`terraform/modules/snyk-ecr-role/`, `examples/`, `tests/`, and `docs/` at the repository root.

## Dependencies & Execution Order

### Phase Dependencies

- **Setup (Phase 1)**: no dependencies.
- **Foundational (Phase 2)**: depends on Setup and blocks every story.
- **User stories (Phases 3 to 6)**: US1 comes first, because every other story starts from a
  connected registry.
- **Polish (Phase 7)**: the docs and the gate follow the stories; the open tasks can run at any time.

### User Story Dependencies

- **US1 (P1)**: depends only on Phase 2.
- **US2 (P2)**: builds on US1's module and example root (T013 to T015).
- **US3 (P2)**: builds on US1's integration lookup (T017), not on US2.
- **US4 (P3)**: builds on US1's integration lookup (T017) and US3's project listing (T028).

### Within Each User Story

- In US1, T013 and T014 come before T015, and T016 to T018 before T019.
- The open tasks are independent of each other. T026 must pass before FR-009 counts as verified
  live, and T038 needs an e2e run if the default version moves.

### Parallel Opportunities

- T002, T003, and T004; T009 and T010.
- In US1, the AWS side and the Snyk side meet only at the role ARN: T013, T014, and T016 in parallel.
- T023 and T024 in US2.
- Among the open tasks: T031, T039, T040, T041, and T042.
